# Soccer Player Rating Estimation

Estimate a soccer player rating from performance attributes.

## Approach

- Data cleaning, duplicate and null handling
- Correlation analysis of performance features
- Linear Regression, Ridge, Lasso, Decision Tree and Random Forest

## Start here

[Soccer_data_Refined.ipynb](Soccer_data_Refined.ipynb)

## Data

Soccer datasets, included as zip files.
